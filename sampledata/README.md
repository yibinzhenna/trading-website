# Sample data

Synthetic bars, generated by a seeded random walk. Three regimes: trending,
choppy, and declining.

They exist so a fresh clone or a fresh deploy works immediately, with no API
key and no provider account.

Being synthetic is deliberate, not a shortcut. Real market data carries
redistribution restrictions that would make committing it to a public
repository a licensing problem. These carry none.

They are not real prices. Do not read anything into a backtest run against them.
